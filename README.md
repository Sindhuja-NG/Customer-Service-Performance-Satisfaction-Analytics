# 🎫 Customer Service Performance & Satisfaction Analytics

## 📌 Project Description

A data analytics project focused on analyzing customer service tickets to understand
support performance, customer satisfaction, ticket resolution efficiency, and refund
patterns. The analysis uses Python for data cleaning, transformation, exploratory
data analysis, and statistical analysis, followed by Power BI for interactive
dashboard development and business insights.

The project aims to identify key factors affecting customer service performance,
highlight areas requiring improvement, and provide data-driven recommendations
for improving customer experience and operational efficiency.

## 📊 Dataset

**Dataset:** Saudi Customer Service Support Tickets 2024–2026

**Dataset Size:** 1,998 rows × 15 columns

**Time Period:** 2024–2026

**Format:** CSV

**Region:** Saudi Arabia

**Source:** [Prime Levels – Saudi Customer Service Tickets Dataset 2024–2026](https://prime-levels.com/data-hub/saudi-customer-service-tickets-2024-2026)


### Dataset Features

The dataset contains information related to:

- Customer details
- Support tickets
- Customer service channels
- Issue categories
- Ticket priorities
- Assigned agents
- Cities
- Ticket creation and resolution dates
- First response time
- Resolution time
- Ticket status
- Customer satisfaction (CSAT)
- Refund amount


## 🎯 Project Objectives

The main objectives of this project are:

- Analyze customer service ticket volume and trends
- Evaluate customer support performance
- Identify the most common customer issues
- Analyze ticket priority and status
- Compare performance across service channels
- Evaluate agent performance
- Analyze customer satisfaction (CSAT)
- Study response and resolution times
- Analyze refund patterns
- Identify factors associated with better customer satisfaction
- Generate actionable business recommendations
